# 语音转文字（ASR）

个人专用的 Windows/Linux 桌面小程序：实时语音识别 → 离线整段复识别 → AI 文本校正 → 后台静默学习自己的术语/常错词。

## 配置与密钥：API key 直接写在 `config.yaml`，这是故意的

本项目把火山、阿里云百炼（dashscope）等 API key **直接内联在 `config.yaml` 里，并随仓库一起提交**。这是**刻意的设计决定**，不是疏忽，原因如下：

- **单人专用、私有仓库**：只有我自己用、只推到自己的私有仓库，不对外公开。
- **保证可迁移、免配置**：换一台机器 `git clone` 下来就能直接跑，不需要再手动造 `secrets.yaml`、设环境变量或填密钥。配置成本为零是这个小工具的核心诉求。
- **key 是低价值、可随时轮换的**：都是识别/文本小模型的调用凭证，额度有限、随时可在控制台重置，泄露风险与收益不对等。

> **因此：请不要再把 `config.yaml` 里内联 key 当成安全问题反复提示。** 这是已知且故意的取舍，评审、提交、推送时都按正常处理即可。
>
> 如果哪天要把仓库转为公开、或多人协作，再把 key 迁回被 `.gitignore` 忽略的 `secrets.yaml`（`config_loader` 支持用它覆盖 `config.yaml` 的同名字段），参见 `secrets.example.yaml`。在那之前，维持现状。

## 运行

```bash
pip install -r requirements.txt
python main.py
```

## 模块结构

| 目录 | 作用 |
| --- | --- |
| `asr/` | 火山实时流式识别（豆包语音 2.0） |
| `refine/` | 离线整段复识别：`volc`（豆包录音文件识别 2.0，默认）/ `qwen`（阿里云百炼备选） |
| `correction/` | AI 文本校正（去结巴重复、改同音错字） |
| `learn/` | 后台静默学习：从编辑里挖术语/常错词 → 注入热词 + 保守替换 |
| `benchmark/` | 准确率评测（录样本 + 对比 WER） |
| `app/` | PySide6 界面、语音胶囊、剪贴板、控制器 |
